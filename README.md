# PODOGERIÁTRICA · Capacitación y Certificaciones

Sitio web institucional de **PODOGERIÁTRICA Capacitación y Certificaciones**, dedicado a:

- **Curso Presencial de Podología (7 meses)** en sedes CDMX y Querétaro.
- **Orientación y acompañamiento SEP-CONOCER EC1417**.
- **Talleres especializados y prácticos**.
- **Catálogo interactivo** de instrumental podológico, kits y módulos educativos digitales con cotizador directo por WhatsApp.

## Estructura del sitio

- `index.html`: Página principal en HTML5 semántico.
- `css/styles.css`: Hoja de estilos en CSS3 Vanilla con paleta institucional y diseño responsivo.
- `js/main.js`: Lógica interactiva (menú móvil, filtros de catálogo, cotizador y formulario conectado a WhatsApp, acordeón FAQ).

## Publicación

Este sitio está preparado para publicarse directamente en **GitHub Pages** desde la rama `main` (carpeta raíz `/`).
